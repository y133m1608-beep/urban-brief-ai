# Urban Brief AI v9 - Category Articles

## 변경 내용
- 메인 뉴스 카드는 분야별 대표 기사로 표시
- 대표 기사 카드를 누르면 해당 분야의 기사 여러 개가 사이드 패널로 열림
- 사이드 패널 안의 기사를 누르면 기사 원문 링크로 이동
- 7개 분야 균형 수집 유지
- 메일 발송은 대표 기사 중심으로 유지

## Vercel Environment Variables
필수:
- RESEND_API_KEY
- RECIPIENT_EMAIL
- NAVER_CLIENT_ID
- NAVER_CLIENT_SECRET


## v10 추가 기능
- 오늘의 주요 뉴스 대표 기사들을 AI가 종합해 `오늘의 건축적 질문`을 자동 생성합니다.
- OPENAI_API_KEY가 없으면 기본 규칙 기반 질문으로 자동 대체됩니다.

## 추가 Vercel Environment Variables
선택:
- OPENAI_API_KEY = OpenAI API Key
- OPENAI_MODEL = gpt-4.1-mini


## v11 추가 기능
- `건축 분야에 미칠 종합 영향`이 고정 문장이 아니라, 오늘 수집된 뉴스 대표 기사들을 바탕으로 AI가 자동 생성합니다.
- OPENAI_API_KEY가 있으면 AI 기반으로 4개 문장을 생성합니다.
- OPENAI_API_KEY가 없으면 뉴스 키워드에 따라 규칙 기반 문장으로 대체됩니다.


## v12 추가 기능
- 분야별 대표 뉴스가 서로 겹치지 않도록 전역 중복 제거 로직을 추가했습니다.
- 기사 URL과 제목을 정규화하여 같은 기사 또는 거의 같은 기사 제목이 다른 분야에 반복 표시되는 것을 줄였습니다.
- 한 분야에서 이미 대표 기사로 선택된 기사는 다른 분야 대표 기사와 기사 목록에서 제외됩니다.


## v13 추가 기능
- `오늘의 공통 흐름`도 고정 문장이 아니라, 오늘 수집된 대표 뉴스들을 바탕으로 AI가 자동 생성합니다.
- OPENAI_API_KEY가 있으면 AI가 공통 흐름을 1개 문단으로 생성합니다.
- OPENAI_API_KEY가 없으면 뉴스 키워드에 따라 규칙 기반 공통 흐름으로 대체됩니다.


## v14 추가 기능
- 기존 7개 분야에 `국제 / 글로벌` 분야를 추가했습니다.
- 국제 / 글로벌 기본 키워드: 글로벌 도시, 해외 주거, 스마트시티
- 메인 브리핑은 이제 8개 분야의 대표 뉴스를 균형 있게 보여줍니다.
- Naver 뉴스 API 기반이므로 해외 이슈도 한국 언론이 보도한 국제/글로벌 도시 뉴스 중심으로 수집됩니다.
- 진짜 영문권 원문 뉴스까지 직접 수집하려면 추후 GNews, NewsAPI, Guardian API 같은 해외 뉴스 API를 추가로 연결할 수 있습니다.


## v15 수정 내용
- `국제 / 글로벌` 분야를 `국제 / 정세`로 수정했습니다.
- 목적: 해외 도시 사례만 보는 것이 아니라 전쟁, 유가, 미국 정치, 세계 경제, 지정학 리스크처럼 건축·도시 조건에 간접적으로 영향을 주는 세계 정세를 함께 수집합니다.
- 기본 키워드: 전쟁, 유가, 미국 정치, 세계 경제, 지정학 리스크
- 건축적 해석 방향: 자재비, 에너지 비용, 공급망, 건설 경기, 도시 인프라 투자, 공공사업 조건 변화


## v16 수정 내용
- `국제 / 정세` 키워드를 특정 인물·사건에만 치우치지 않도록 재구성했습니다.
- 기존: 전쟁, 유가, 미국 정치, 세계 경제, 지정학 리스크
- 수정: 국제분쟁, 에너지, 세계경제, 공급망, 기후외교, 미국대선, 중국경제
- 의도: 세계 정세를 전쟁/유가 중심으로만 좁히지 않고, 에너지·공급망·기후외교·미중 경제 흐름까지 함께 읽도록 확장했습니다.
- 건축적 해석 방향: 공사비, 자재 수급, 에너지 비용, 인프라 투자, 도시정책, 부동산 시장, 기후 대응 기준 변화


## v18 수정 내용
- v17에서 국제/정세 뉴스 로딩이 멈추던 코드 오류를 수정했습니다.
- `국제 / 정세` 분야는 GNEWS_API_KEY가 있으면 GNews 해외 뉴스를 우선 사용합니다.
- GNEWS_API_KEY가 없거나 실패하면 기존 네이버 뉴스 API로 대체됩니다.
- 추가 환경변수: GNEWS_API_KEY


## v19 수정 내용
- `국제 / 정세` 분야를 국내 국제정세 기사 + 해외 원문 뉴스가 함께 나오도록 수정했습니다.
- 국내 보도: 네이버 뉴스 API 사용
- 해외 원문: GNews API 사용
- 기사 카드에는 `국내 보도` 또는 `해외 원문` 태그가 표시됩니다.
- GNEWS_API_KEY에 Resend/OpenAI 키처럼 `sk_`, `re_`로 시작하는 잘못된 키가 들어가면 해외 API 호출을 하지 않고 국내 기사로 대체합니다.
- GNews API 키가 없거나 잘못되면 국제/정세 분야는 네이버 뉴스 API 기반 국내 보도만 표시됩니다.


## v20 추가 기능
- `4. 오늘의 건축 키워드`도 고정값이 아니라 오늘 수집된 뉴스 대표 기사들을 바탕으로 AI가 자동 추출합니다.
- OPENAI_API_KEY가 있으면 AI가 건축 키워드를 생성합니다.
- OPENAI_API_KEY가 없으면 뉴스 키워드에 따라 규칙 기반 건축 키워드로 대체됩니다.

  - 오늘의 건축 키워드 자동 생성
  - 오늘의 건축적 질문 자동 생성
  - 국제 / 정세 뉴스 혼합 수집
