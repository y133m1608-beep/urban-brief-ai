# Urban Brief AI v9 - Category Articles

## 변경 내용
- 메인 뉴스 카드는 분야별 대표 기사로 표시
- 대표 기사 카드를 누르면 해당 분야의 기사 여러 개가 사이드 패널로 열림
- 사이드 패널 안의 기사를 누르면 기사 원문 링크로 이동
- 7개 분야 균형 수집 유지
- 메일 발송은 대표 기사 중심으로 유지
